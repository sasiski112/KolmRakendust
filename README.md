# Harjutus: Kolm rakendust (Windows Form)

Lahendus koosneb neljast projektist:

| Projekt | Kirjeldus |
|---|---|
| `Launcher` | Avavorm, mille nupud avavad iga rakenduse |
| `PildiVaataja` | Pildi vaatamise programm |
| `MatemaatikaMang` | Matemaatiline äraarvamismäng |
| `SarnasteMang` | Sarnaste piltide leidmise mäng |

Iga projekti kaustas on oma `README.md`.

## Käivitamine
Vajalik: Windows ja .NET 8 SDK (või Visual Studio 2022).

```
dotnet run --project Launcher
```
või ava `KolmRakendust.sln` Visual Studios ja vali käivitusprojektiks `Launcher`.

Kogu liides on loodud koodis (Toolbox'i ja Designer'it ei kasutatud).
